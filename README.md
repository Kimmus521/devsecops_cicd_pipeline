# DevSecOps CI/CD Pipeline

## Project Goal

This project demonstrates a secure CI/CD pipeline for a containerized Python web application.

The pipeline will progressively integrate:

- Automated testing
- Static Application Security Testing (SAST)
- Secret scanning
- Docker containerization
- Container vulnerability scanning
- AWS deployment
- GitHub Actions
- AWS IAM OIDC authentication

## Technology Stack

- Python
- Flask
- GitHub Actions
- Docker
- AWS
- Bandit
- Gitleaks
- Trivy
